# Сравнительный анализ VLM моделей для извлечения параметров из научных публикаций

## 📊 Обзор исследования

**Задача:** Извлечение количественных параметров из графиков и таблиц научных статей по наноматериалам

**Датасеты:** 
- 5 категорий: Synergy, Cytotoxicity, Magnetic, Nanozymes, Selective Toxicity
- Всего: 2307 PDF файлов
- Разбивка: train/test для каждой категории

## 🤖 Тестируемые модели

### 1. GLM-4.1V-9B-Thinking
- **Статус:** Заменен на Qwen2.5-VL
- **Покрытие:** 100% (2307/2307) в первоначальных тестах
- **Качество:** Низкое извлечение параметров

### 2. Google Gemma-3-27b-it
- **Покрытие:** 52% (1197/2307 файлов)
- **Особенность:** Обрабатывал только файлы с CSV разметкой
- **Качество:** Не извлек значимых параметров
- **Время обработки:** ~7 часов

### 3. Qwen2.5-VL-72B-Instruct-AWQ (НОВАЯ)
- **Покрытие:** В процессе (цель 100%)
- **Качество:** 16.4% успешных извлечений (лучший результат)
- **Скорость:** ~40-50 файлов/час

## 💡 Ключевые выводы

### Сильные стороны Qwen2.5-VL-72B:
1. **Лучшее качество извлечения** среди всех протестированных моделей
2. **Стабильная работа** без зависаний и ошибок

3. **Ограниченный ground truth** - нужна расширенная разметка
