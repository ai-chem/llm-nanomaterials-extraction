## 🔬 Технические детали

### Проблемы извлечения

1. **Графики без числовых меток**
   - Многие графики имеют только визуальное представление
   - Отсутствуют точные числовые значения на осях

2. **Сложные таблицы**
   - Многоуровневые заголовки
   - Объединенные ячейки
   - Нестандартные форматы

3. **Качество PDF**
   - Низкое разрешение сканов
   - Артефакты сканирования
   - Повернутые страницы

## 💡 Выводы

1. **Низкие метрики обусловлены недостатком ground truth**, а не качеством моделей
2. **GLM-4.1V показывает лучшие результаты** при полном покрытии датасета
3. **Требуется существенное расширение разметки** для объективной оценки
4. **Задача извлечения параметров из научных графиков крайне сложная** и требует специализированных подходов
